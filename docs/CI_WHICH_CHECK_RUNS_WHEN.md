# Which check runs when (state after CI package B, 2026-11-14)

Required checks (branch ruleset): `quality`, `security`, `infrastructure`. Nothing else blocks a merge.
Wall-clock figures are from real runs of PR #1359 (the pull-request head), not estimates; the `quality` row is re-measured (main `51185f2d8`, see its row).

Rules of thumb
- A run that does not appear in the check list of a PR did not start because no path of its filter changed. That is intended, not a skipped check.
- `quality` is the only gate over several jobs. A red `lint`, `tests` or `packaging` makes `quality` red; a skipped `packaging` is accepted only when `changes` reports that no packaging input changed.
- Shard weights: `python -m tests.pytest_shards weights --from-artifacts > tests/pytest_shard_weights.json` rebuilds the table from the JUnit artifacts of the latest main run (`--qualification` for `tests/qualification`). Refresh whenever more than 3 % of test files are unweighted or a slot stays more than 25 % slower than the fastest slot. A new test file without a weight is allowed; the guard fails only for a table entry of a missing file or when more than 5 % of the files are unweighted.
