Dated model-precision and simulation-fidelity closeouts, retained for provenance.

**Not authority.** This directory is a near-twin of `docs/decision-quality/`
(hyphen). Both exist, neither is empty, and neither is referenced by `AGENTS.md` or by
`docs/foundry-execution/README.md`. The separator difference is the only distinction and
it is not a meaningful one — treat the two as one topic split across two folders, not as
a canonical and a non-canonical side.

Contents:

- `MODEL_PRECISION_POLICY_CURRENT.md` — "frozen for next fresh RogShai optimization
  campaign", effective 2026-08-20, 4-player operational pod size, evidence class

  status claim (`AGENTS.md` §3). Its 4-player scope is a historical campaign
  constraint; it does not constrain `PROJECT_MISSION.md`, which is player-count
  neutral and requires 2–5P technical conformance.
- `SIMULATION_FIDELITY_124_CLOSEOUT_CURRENT.md` — 2026-08-21 closeout of a specific
  simulation-fidelity milestone. `PASS` there is a statement about that milestone
  under `AGENTS.md` §4 at that time; it is not a current project-level PASS and must
  not be cited as one.
