## PB-03 and PB-05 adjudication

- **PB-03 — `BOTH_VALID_DIFFERENT_SCOPE`, now merged into one mechanism.** SB's
  transport-seam blocker (14 engine-supported rows with no protocol verb reaching
  native restoration) and main's admissibility path are the same obligation
  measured on different candidate identities. The converged runner settles
  admissibility from the engine's own per-dimension restoration manifest when one is
  published, because a bare boolean cannot say which dimensions can be restored,
  and falls back to main's candidate-aware reason otherwise. The transport seam is
  still open; nothing was marked resolved to make documents agree.
- **PB-05 — `DIFFERENT_CANDIDATE_SCOPE` / `MAIN_SUPERSEDES_BUNNY` on mechanism.**
  Main's fail-closed build-provenance consumption is retained and is the stronger
  mechanism. It is scoped to the bridge that emits those fields. The pinned upstream
  column runs through a bridge that does not, so PB-05 credit for the pinned column
  remains **withheld**, which is the correct fail-closed outcome rather than a gap
  to be closed by inference.
