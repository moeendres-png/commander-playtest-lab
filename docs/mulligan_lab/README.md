# Mulligan Lab

The Mulligan Lab evaluates current-deck opening hands using exact hypergeometric category baselines, deterministic Monte Carlo samples and a cheap structural milestone follow-up.

Truth boundaries:

- commanders remain in the command zone;
- multiplayer uses one free first mulligan;
- every mulligan redraws seven cards before bottoming;
- generated keep rules are candidate model rules, not universal or empirical claims;
- complete matchup performance is not inferred from hand quality;
- no external rules engine is claimed.
