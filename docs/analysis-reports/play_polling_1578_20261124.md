## P-C: warum nicht gemessen

Die Messung braucht die echte Seite im Browser und das Zählen ihrer Anfragen. Der Browser-Helfer des
Studios erlaubt keinen Zugriff auf den JavaScript-Kontext der Seite (`window`, `page.evaluate` nicht
verfügbar, Meldung `GUEST_JS_EVALUATION_UNSUPPORTED`), also lässt sich weder der Zähler setzen noch auslesen.
Das ist eine Werkzeuggrenze und wird nicht umgangen; ein Skript-Client gegen die HTTP-Routen wäre ein
nachgebauter Client und zählt nach SR34 nicht als Browser-Messung.

## Messanleitung für den Owner-PC (Browser mit Entwicklerkonsole)

Vorher = Stand `63b6fff8e` (unmittelbar vor #1644), nachher = `main`. Je ein Studio auf einer Kopie des Stores
starten (`COMMANDER_LAB_STUDIO_DATA=<Kopie>`, `python -m commander_lab.studio serve --port 8771` bzw. `8772`).
Auf der Seite `partie.html` in der Konsole einmal einfügen:

```js
window.__rt = [];
(function () { const f = window.fetch; window.fetch = function (u, o) {
  const t0 = performance.now(); const m = ((o && o.method) || 'GET').toUpperCase(); const p = String(u);
  return f.apply(this, arguments).then(function (r) { window.__rt.push({ m, p, t0, ms: performance.now() - t0, s: r.status }); return r; });
}; })();
window.__summary = function () {
  const L = window.__rt; const posts = L.filter(e => e.m === 'POST' && /\/decision$/.test(e.p));
  const gets = L.filter(e => e.m === 'GET' && /^\/api\/play\/[^/?]+(\?|$)/.test(e.p));
  const held = gets.filter(e => /wait_ms=/.test(e.p));
  const med = a => a.length ? a.slice().sort((x, y) => x - y)[Math.floor(a.length / 2)] : null;
  const gaps = posts.slice(1).map((e, i) => Math.round(e.t0 - posts[i].t0));
  return { posts: posts.length, state_gets: gets.length, held: held.length, plain: gets.length - held.length,
    gap_ms_median: med(gaps), gap_n: gaps.length, post_ms_median: med(posts.map(e => Math.round(e.ms))) };
};
```

Dann eine Partie mit gleichem Seed und gleicher KI-Pause starten, „Vorspulen bis zu meiner nächsten
Entscheidung“ einschalten, bis mindestens 40 Antworten des Menschen oder zum Spielende spielen und
`JSON.stringify(__summary())` ausgeben. Aussagekräftig sind: `plain` je `posts` (erwartet: vorher etwa 1,
nachher etwa 0), `gap_ms_median` und `post_ms_median`. Die Seite danach nicht neu laden (der Zähler ginge verloren).
Jeder Lauf ist eine Partie mit einem Menschen und damit kein Simulationsergebnis.
