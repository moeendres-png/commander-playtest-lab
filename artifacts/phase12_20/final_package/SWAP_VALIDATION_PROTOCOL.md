# Swap Validation Protocol

A card or package proposal progresses only through evidence gates; no gate applies a change.

1. Formal legality and 100-card/singleton/color-identity checks.
2. Physical inventory and simultaneous-allocation checks.
3. Whole-deck structural role/package screening.
4. Paired Common-Random-Numbers comparison.
5. Holdout pods not reused as the primary comparison.
6. 3/4/5-player, pilot and politics sensitivity.
7. Commander-denial/dependency and rebuild checks.
8. Tactical Oracle only for interactions it actually models.
9. External XMage/Forge evidence only after a real external-rules-engine handshake and action loop.
10. Provider cross-check when both external providers are available.
11. Recommendation status may remain `insufficient_evidence`; no automatic deck or allocation mutation exists.

Evidence ladder: `candidate_swap` → `formally_valid` → `structurally_supported` → `robust_in_structural_holdout` → `tactical_oracle_supported` → `external_engine_supported` → `provider_cross_checked` → `recommended_upgrade`.
