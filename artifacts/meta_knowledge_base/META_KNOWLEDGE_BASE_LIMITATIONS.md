# Meta Knowledge Base Limitations

- The Meta Knowledge Base is an evidence layer only. It does not replace current decklists, inventory, allocation, or local opponent lists.
- cEDH tournament results are structure, package, sequencing and interaction benchmarks unless a matching local play context is explicitly established.
- The initial snapshot uses a small sample: 8 deck snapshots, 3 primer references and 5 tournament result records. Small-sample warnings are preserved in card-frequency outputs.
- Some sources provide full public decklist tables; others are aggregate or partial reference extractions. Each record carries source, confidence and license notes.
- No external XMage/Forge validation was run in this phase.
- No real playtest calibration was performed because no real playtest dataset is present.
- No Meta record may be treated as proof that a card is physically owned.
- No Meta record may trigger automatic card changes.
