# Fair Comparison Contract (narrative; machine companion: FAIR_COMPARISON_CONTRACT.json)

Minimum common treatment for admitted candidates in full qualification:

same current domain authority · same mandatory fixture contract (135/135,
frozen seeds) · same evidence vocabulary · same process-isolation rule ·
same RNG/replay semantic bar · same hidden-info bar · same current Rules
interpretations · same actual-card denominator · same failure semantics ·
same scoring rule (a gate is PASS only if every mandatory item is
PASS + RUNTIME_VERIFIED + current).

Candidate-specific harness mechanics are allowed (drivers, seams,
projections, mapping layers). Candidate-specific evidence standards are
not: no alternative verdict vocabularies, no weaker satisfying pairs, no
construction-counts-as-behavior, no README-as-evidence.

Admission (the bar) and Provider Selection are separate decisions; this
contract binds the qualification comparison itself.
