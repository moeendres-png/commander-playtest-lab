   2026-08-07) — ultimate authority (the document says so, Introduction).
2. Official Oracle text per face (field snapshot) — canonical card function.
3. Official per-card rulings (this capture) — Wizards-published application
   guidance, informative where CR/Oracle are silent, void where contradicting
   them (no contradiction observed in-denominator).

   B&R announcements) — PROVENANCE ONLY for recent changes (dates, unbans);
   never substitutes for the canonical documents. The 2026-02-09 Commander
