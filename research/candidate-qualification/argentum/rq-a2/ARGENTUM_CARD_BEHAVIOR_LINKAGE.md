# RQ-A2 — Argentum Card ↔ Behavior Test Linkage (U5)

Classification of inventory facts: `DIRECTLY_VERIFIED` (mechanical script output at the
lock; script: `research/candidate-qualification/argentum/rq-a2/scripts/card_linkage.py`).
Machine-readable sidecar: `ARGENTUM_CARD_BEHAVIOR_LINKAGE.json` (+ `u5-named-mc.json`).

## 1. Methodology (mechanical, reproducible, no inference across classes)

- **Corpus scan**: `\b(?:card|basicLand)\("…"` over `mtg-sets/*/src/main/**/*.kt`
  (18,526 source files) → canonical implementations; files carrying the
  `GENERATED by mtgish` header → generated drafts; `name = "…"` in files containing
  `Printing(` → reprint rows.
- **Test scan**: 4,199 `*Test.kt` files (rules-engine, all era `tests` children,
  game-server, gym*) + 68 e2e specs + 1,177 manual-scenario JSON boards.
- **BEHAVIOR_ORIENTED_TEST** = test file/class name matches the card name after stripping
  `ScenarioTest|MultiplayerTest|CommanderTest|Test|Spec` and lowercasing alphanumerics
  (3,347 links, strong), OR the card name appears as a quoted literal in a test file that
  uses driver/scenario patterns (`ScenarioTestBase`, `GameTestDriver`, `initGame`,
  `putCreatureOnBattlefield`, …) — heuristic, counted separately.
- **MENTIONED_IN_TEST** = quoted literal anywhere in unit/manual/e2e tests (noisy for
  basics and oracle-text words; reported separately, never equated with behavior).
- **MULTIPLAYER/COMMANDER_BEHAVIOR_TEST** = behavior-linked file that additionally matches
  multiplayer (`initMultiplayer`, `TwoHeadedGiant`, `CommanderPod`, …) / commander
  (`Format.Commander`, `commanderCardName`, …) patterns. The headline cut uses named-class
  links only (10 multiplayer, 1 commander); the looser mention cut is reported for contrast.
- **UNKNOWN** = declared name with zero test signal of any kind. Filename heuristics are
  never used as proof (stated explicitly wherever a count could be misread).

## 4. Reading the result

- Executable-coverage claims remain unsupported: 57% of declared names have no test signal
  at all, and the 34% behavior-linked share mixes strong (named-class) with heuristic
  (driver-mention) evidence. Card-name counts must not be cited as behavior coverage.
- Multiplayer/commander card-level testing is thin in absolute terms (10 named multiplayer,
  1 named commander), though engine-level multiplayer/commander suites exist (see RQ-A1 test
  corpus + RQ-A2 U10 runtime probes).
- The `Lightning Bolt` shadow case (test def overriding the real def in the test registry)
  is a methodology caveat for any name-based linkage: test behavior may exercise a
  different definition than production runs.
